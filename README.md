# Подбор хороших вин

Приложение к ДЗ-3. Логистическая регрессия по 12 физико-химическим характеристикам оценивает вероятность того, что вино хорошее (экспертная оценка не ниже 7). Модель не обучается внутри приложения, загружается из `model.joblib`.

## Содержимое

- `app.py` — приложение
- `model.joblib` — пайплайн StandardScaler + LogisticRegression, обучен на трейне
- `config.json` — порог 0.268, подобран на валидации по максимуму F1
- `test.csv` — тестовая выборка со столбцом target
- `requirements.txt` — версии библиотек

## Запуск

Python 3.12.

```bash
cd wine_app
py -3.12 -m pip install -r requirements.txt
py -3.12 -m streamlit run app.py
```

Адрес: http://localhost:8501

Версию scikit-learn менять нельзя: `model.joblib` сохранён ей.

## Вкладки

1. Одно вино — ввод 12 признаков, вероятность и решение при текущем пороге. Значения по умолчанию равны медианам по `test.csv`, границы ползунков равны минимуму и максимуму.
2. Модельные метрики — при сдвиге порога пересчитываются матрица ошибок, precision, recall, F1. На ROC- и PR-кривых отмечена текущая точка.
3. Пакетное предсказание — загрузка CSV без столбца target, таблица с вероятностями и решениями, выгрузка результата. При нехватке столбцов выводится их список.
4. Что выучила модель — коэффициенты после масштабирования, отсортированные по значению.

Порог задаётся одним ползунком в сайдбаре и действует на всех вкладках.

## Кэширование

`st.cache_resource` используется для модели: это один тяжёлый объект на весь сервер, декоратор хранит единственный экземпляр и отдаёт ссылку на него без копирования.

`st.cache_data` используется для `config.json`, `test.csv` и вероятностей на тесте: декоратор сериализует результат и отдаёт каждой сессии свою копию, поэтому изменение данных в одной сессии не затрагивает остальные. Для модели этот режим не подходит, копировать обученный пайплайн на каждую сессию дорого и бессмысленно.

Без декоратора `joblib.load` выполнялся бы заново при каждом действии пользователя, так как Streamlit перезапускает скрипт сверху вниз на любое изменение виджета. Вместе с этим пересчитывался бы `predict_proba` на всех 1950 объектах теста, хотя от порога вероятности не зависят, от порога зависит только сравнение с ним.
